# ☕ Cafe Management System

A simple Cafe Management System made using Python and Tkinter. I created this project to practice GUI development and improve my Python programming skills. It is a beginner-friendly desktop application that helps take customer orders and generate receipts automatically.

## 📌 Features

* Attractive GUI using Tkinter
* Menu with item prices
* Enter quantity for each item
* Automatic bill calculation
* Receipt generation
* Clear all fields option
* Exit button

## 🛠️ Technologies Used

* Python
* Tkinter

## 📋 Menu Items Included

* Coffee
* Tea
* Sandwich
* Burger
* Pizza
* Fries
* Cold Drink
* Cake

## 🚀 How to Run

1. Make sure Python is installed on your computer
2. Download or clone this repository
3. Open terminal in project folder
4. Run the file:

```bash
python cafe_management.py
```

## 🎯 Purpose of This Project

I created this project for learning purposes to understand:

* Python GUI development
* Functions and classes
* Bill calculation logic
* User input handling
* Tkinter widgets and layout

## 📷 Output

The project shows a cafe menu on one side and generates the receipt on the other side.
